A fast, dependency-free make.fun frontend: live bounty board, bounty pages, leaderboards and profiles — static files, no build step, first load under 10 KB gzip.

## Run it

```sh
python3 -m http.server --directory app 8080
# open http://localhost:8080
```

Build the judged dossier with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
